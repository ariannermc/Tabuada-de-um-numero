# Tabuada de um Número
 
> O usuário digita um número e o programa gera a tabuada completa do número no terminal.

## Funcionalidades
 
- O usuário escolhe qual tabuada quer ver
- Exibe a tabuada completa do número (até o 10)

---
 
## Como executar
 
**Pré-requisito:** Java instalado. Verifique com:
```bash
java -version
```
 
1. Clone o repositório:
```bash
git clone https://github.com/ariannermc/Tabuada-de-um-numero.git
cd Tabuada-de-um-numero
```
 
2. Compile o arquivo:
```bash
javac Tabuada.java
```
 
3. Execute o programa:
```bash
java Tabuada
```
 
4. Digite o número desejado quando solicitado:
```
Digite um número para imprimir a tabuada: 
```
